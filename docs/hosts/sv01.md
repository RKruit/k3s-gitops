## systemd

- `sv01-config-sync.timer`: boot +90 s, then every 5 min.
- `sv01-config-sync.service` (oneshot, User=rkruit, WorkingDirectory=/opt/sv01-config):
  1. `git pull --ff-only`
  2. `docker compose --env-file /srv/sv01-secrets/sv01.env --project-name sv01 -f /opt/sv01-config/sv01/compose/docker-compose.yml up -d --remove-orphans`
- `gh-webhook.service`: GitHub push-webhook receiver on `127.0.0.1:9100` — restarts the sync unit on a signed push ([webhook-deploy](../infra/webhook-deploy.md)).
- Force: `sudo systemctl restart sv01-config-sync.service` — verify with `systemctl status` (all ExecStart lines `0/SUCCESS`).

## Gotchas

- Always `sudo docker …` — rkruit's docker-group membership is read at login; already-running sessions may lack it.
- The timer does **not** re-pull `latest` images: run `docker compose pull` (as rkruit) after pushing a new image.
- Git-pull on `/opt/sv01-config` must run as rkruit; as root it fails on missing GitHub SSH known_hosts.
